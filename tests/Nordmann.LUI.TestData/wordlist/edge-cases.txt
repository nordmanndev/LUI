# The stride sample next to this file (german-words.sample.txt) covers the
# German alphabet. This file covers what a stride cannot reach for: the
# characters where the German transliteration, the accent removal and the
# tokeniser's own folding disagree.
#
# Format:  <input> TAB <expected search form> TAB <expected compact form>
#
# The expectations are *measured*, not assumed: they are what FTS5's trigram
# tokenizer produces for the input, confirmed by the parity test against the
# live tokenizer. A line that does not start with a tab-separated value is a
# comment.
#
# The search form is the fully folded text (lower case, without diacritics,
# with the German transliteration). The column of the index holds the
# transliterated text *before* the folding — the tokeniser folds it when it
# indexes it.

# --- the characters the tokeniser folds in its own way ------------------------
# The capital sharp s folds to the small one — and the German transliteration
# then makes both of them "ss".
ẞ	ss	ss

# The Polish l has no decomposition, so the tokeniser keeps it (and lowercases
# it). The accents around it are removed.
Łódź	łodz	łodz

# The Turkish dotted capital I folds to a plain "i" — unlike .NET, which
# leaves it alone. The dotless i stays as it is.
