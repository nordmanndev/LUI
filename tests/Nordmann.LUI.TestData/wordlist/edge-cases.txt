#
# The stride sample next to this file (german-words.sample.txt) covers the
# German alphabet. This file covers what a stride cannot reach for: the
# characters where the German transliteration, the accent removal and the
# tokeniser's own folding disagree.
#
# Format:  <input> TAB <expected s_norm> TAB <expected s_compact>
#
# A line with only <input> is *executed but not asserted*. Those are the
# characters whose behaviour PR-002 measures first: the expectations depend on
# how FTS5's trigram tokeniser folds a case, and the C# normaliser has to
# match that measurement rather than the other way round. Once measured, the
# expectation moves into this file and the case becomes asserted.
#
# The expectations below are the ones the specification states directly (§6.1).
