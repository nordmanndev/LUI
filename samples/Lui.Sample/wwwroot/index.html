LUI — sample foundation

The sample wires the LUI API to a browser. It arrives with the library — this page is the shell it will fill.

What the sample will show

  • A search field backed by flexdatalist, served from the LUI API
  • A control panel with every query option: take, candidates, ranking, priority, similarity, typo tolerance, highlight, timings
  • The raw LuiResult JSON, so every rule is visible and not just asserted
  • The write side: upsert, weight, priority, remove, sync, check, rebuild

Endpoints

  • GET /api/health
  • GET /api/indexes
